# MPU6050



### Overview

This library ports IMU (gyro and accelerometer) functionality of a MPU6050 6 axis IMU from TEMU. This library will be optimized later probably



### IOC Setup

###### GPIO:

1. Go to the view of the processor pinout (the page with all the circles) and:

   1. set "PF0" to "I2C2\_SDA"
   2. set "PF1" it "I2C2\_SCL"
   3. set "PB15" to "GPIO\_Output"
2. Go to the "System Core" dropdown on the left of the screen and click "GPIO"

   1. Click on the "PB15" line and set "GPIO Output Level" to "High"



###### I2C2:

1. Click on "I2C2" in the "Connectivity" drop down
2. Select the I2C" option in the "Mode" dropdown
3. In the "Parameter Settings" tab set:

   1. I2C Speed Mode to "Standard Mode"
   2. I2C Clock Speed to "100000"


### Include Setup

1. Navigate to your main.h file

2\. Include the MPU6050 library by adding the following to the file in the "USER CODE BEGIN Includes" section:


&#x09;#define INCLUDE\_MPU6050

&#x09;#include "MPU6050.h"



### Library Handler Setup

1. Navigate to the "StartLibraryHandler" task in your main.c file
2. After the "USER CODE BEGIN" comment, but before the loop, add the following to initialize library and set the sensitivities of the GYRO and Accelerometer

MPU6050\_ACCEL\_SENS(3);
MPU6050\_GYRO_SENS(3);
MPU6050\_INIT();

3. Inside the for loop add the following

MPU6050\_Update();



### Functions

#### INITIALIZING FUNCTIONS

##### void MPU6050_GYRO_SENS(uint8_t fullScaleSensitivity);

###### Params:

&#x09;uint8\_t fullScaleSensitivity  -  This parameter determines the sensitivity of the IMU which follows the following scale:
   0 = ±250°/s
   1 = ±500°/s
   2 = ±1000°/s
   3 = ±2000°/s
It's recommended to stick with 3

###### Returns:

&#x09;void

##### void MPU6050_ACCEL_SENS(uint8_t fullScaleSensitivity);

###### Params:

&#x09;uint8\_t fullScaleSensitivity  -  This parameter determines the sensitivity of the IMU which follows the following scale:
   0 = ±2g
   1 = ±4g
   2 = ±8g
   3 = ±16g
It's recommended to stick with 3

###### Returns:

&#x09;void
