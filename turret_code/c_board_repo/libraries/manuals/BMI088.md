# BMI088



### Overview

This library ports IMU (gyro and accelerometer) functionality from previous years. Layout for this library is not ideal due to it just being a rough rip from the DJI drivers.

REV01: Major overhaul of alot of useless functions in the library! Deleted a ton of stuff and it should all still work!



### IOC Setup

###### TIMER 10:

1. Open the .ioc editor window by double clicking on your .ioc file in the Project Explorer view
2. Click on "TIM 10" in the "Timers" drop down
3. Click on the "Activated" checkbox
4. Select "PWM Generation CH1" for the "Channel1" dropdown
5. In the "Parameter Settings" tab set the "Counter Period (AutoReload Register - 16 bits value)" to 4499
6. Go to the view of the processor pinout (the page with all the circles) and set "PF6" to "TIM10\_CH1"
7. In the "GPIO Settings" tab click on the available pin and:

   1. set "GPIO Pull-up/Pull-down" to "Pull-up"
   2. set "Maximum Output Speed" to "High"



###### SPI 1:

1. Click on "SPI1" in the "Connectivity" drop down
2. Select the "Full-Duplex Master" option in the "Mode" dropdown
3. In the "Parameter Settings" tab set:

   1. Your Prescaler (for Baud Rate)" to 256 (make sure the resulting bud ate is 328.125KB/s)
   2. "Clock Polarity" to "High"
   3. "Clock Phase" to "2 Edge"

4. Go to the view of the processor pinout (the page with all the circles) and do the following
10. Find "PA7", click on it and set it to "SPI1\_MOSI"



###### GPIO:

1. Go to the view of the processor pinout (the page with all the circles) and:

   1. set "PB0" to GPIO\_Output"
   2. set "PA4" to GPIO\_Output"
   3. set "PC4" to GPIO\_EXTI4"
   4. set "PC5" to GPIO\_EXTI5"
2. Go to the "System Core" dropdown on the left of the screen and click "GPIO"

   1. Click on the "PC4" line and add "INT1\_ACCEL\_Pin" as the user label
   2. Click on the "PC5" line and add "INT1\_GYRO\_Pin" as the user label



### Include Setup

1. Navigate to your main.h file

2\. Include the BMI088 library by adding the following to the file in the "USER CODE BEGIN Includes" section:

&#x09;#define INCLUDE\_BMI088

&#x09;#include "BMI088.h"


### Library Handler Setup

1. Navigate to the "StartLibraryHandler" task in your main.c file
2. After the "USER CODE BEGIN" comment, but before the loop, add the following to initialize library and set the sensitivities of the GYRO and Accelerometer

BMI088\_INIT();

3. Inside the for loop add the following

BMI088\_Update(5);


### Start Main Task Setup

1. Navigate to the "StartMainTask" task in your main.c file
2. after the "USER CODE BEGIN" comment, but right before the "Infinite Loop" comment, add the following to offset the startup of the IMU

osDelay(200);



### Functions

##### void BMI088\_Update(uint8_t delay)

###### Params:

&#x09; delay  -  delay in miliseconds per PWM Heater (You are unable to change the update speed of the IMU)

###### Returns:

&#x09; NULL





##### float IMU\_get\_gyro(Axis)

###### Params:

&#x09;Axis  -  x,y, or z

###### Returns:

&#x09;float  -   current rotational speed around selected axis





##### float IMU\_get\_accel(Axis)

###### Params:

&#x09;Axis  -  x,y, or z

###### Returns:

&#x09;float  -   current acceleration in selected axis
